What the installer changes

It backs up anything it replaces and is safe to re-run. Settings are added only where a key is absent, except the four view settings, which it sets unless you changed one by hand after an earlier install. It also adds two turn-meter hooks, one on prompt submit and one on stop. --no-view leaves the mobile view out.

WhereChange
~/.claude/CLAUDE.mdAppends one line, @~/.claude/usage-optimizer/POLICY.md. Rules for one machine go above it.
~/.claude/settings.jsonAdds, if absent: model opus[1m] and effortLevel xhigh (from explore.main_session in arms.json), autoCompactWindow 250000 (moved from 450000), cleanupPeriodDays 30, CLAUDE_CODE_SUBAGENT_MODEL=sonnet, its status line, and the turn-meter UserPromptSubmit and Stop hooks. Sets the view: verbose false, viewMode default, tui fullscreen, outputStyle Mobile. Your permission mode is left alone.
~/.claude/agents/scout, digest, researcher on Sonnet; verifier on Opus.
~/.claude/skills/mobile-view/The mobile view: each tool call folds to one line (click to open it), long code blocks fold, questions are numbered, . in an empty prompt lists them and jumps back to one (Esc goes back), /mobile-view off turns it off.
~/.claude/output-styles/Mobile.mdShort narration between steps, no long code in replies, a self-contained final answer.
~/.claude/usage-optimizer/The policy, the arms catalog arms.json, and lane, lane-stats, lane-mask, usage-status, turn-meter, claude-statusline, claude-prompts.
~/.local/bin/Symlinks to the tools. On Windows, bash and .cmd wrappers for lane, lane-stats, usage-status, claude-statusline and claude-prompts that run them with the Python the installer found.
~/.config/lanes/An empty mask.local for that machine's own secret paths.

What we measured

Claude Max 20x: about $1,525 API-list value per week ($1,017–3,050) and $254 per 5h ($235–277). Fable draws from the shared week, with a 50% sub-cap. Cache-read charging remains unresolved.

Codex Pro Lite: about 8,400 credits per week (7,800–9,200), about $340 API value. Plus: about 1,450 credits per week. These are measured allowances, not guarantees.

The findings are our own measurements of the plan limits and of every model at every effort on a 36-item review suite, compared with public benchmarks. The bundle carries the data and the tools to regenerate them.

  • findings/FINDINGS.md, findings/findings.json, findings/public.json
  • findings/suite-r/: stats, compare, priors, outcomes.jsonl, panels
  • measure/: the meter probes
  • bin/lane-bench: grade, stats, compare, priors, export, panels

All under ~/.claude/usage-optimizer/.
