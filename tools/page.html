After the install, work as usual. The policy tells your agent to plan, send each written unit to a worker lane (lane-stats pick, then lane), review every diff, and end each report with a Cost line and a Time line. Three commands to know: usage-status (what is left in every plan), lane-stats report (what each worker arm delivered) and turn-meter report (each turn's cost and time).

The two-line status line shows the session, the running turn and every plan's window; the mobile view folds each tool call to one line.

Codex compacts by itself, and its own subagents draw on the same ChatGPT window as the luna, terra, sol and astra lanes. Claude arms run as processes or with --cloud.

The kit's status item shows the turn's ETA and cost, the plan meters and the kit release. Claude arms and some amp arms run inside the Amp thread through the plugin. The mobile view, sessions pane and other mods are Claude Code only.

What the installer changes

It backs up anything it replaces and is safe to re-run. Every install writes the same kit files; then it adds the adapter for each agent it installs for (--platform claude-code, codex or amp, comma-separated; without it, the agents this machine already has, else Claude Code).

For Claude Code, settings are added only where a key is absent, except the four view settings, which it sets unless you changed one by hand after an earlier install. It also adds two turn-meter hooks, one on prompt submit and one on stop. --no-view leaves the mobile view out.

What we measured

Claude Max (from 2026-11-13): about $1,440 of non-Fable API-list value per week, a 5h window of about $165–175 of Opus list, and Fable's own cap at about $240 of Fable list. Before that, on Max 20x (now called Ultra): about $1,525 per week ($1,017–3,050) and $254 per 5h ($235–277). Fable draws from the shared week, with a 50% sub-cap, and weighs about 3.3x Opus per list dollar.

Codex Pro Lite: about 8,400 credits per week (7,800–9,200) until 2026-10-29, then about 16,800 after OpenAI doubled the Pro tiers' limits. Plus: about 1,450 credits per week. The Free plan has one 30-day window. These are measured allowances, not guarantees.

The findings are our own measurements of the plan limits and of every model at every effort on a 36-item review suite, compared with public benchmarks. The bundle carries the data and the tools to regenerate them.

  • findings/FINDINGS.md, findings/findings.json, findings/public.json
  • findings/suite-r/: stats, compare, priors, outcomes.jsonl, panels
  • measure/: the meter probes
  • bin/lane-bench: grade, stats, compare, priors, export, panels

All under ~/.claude/usage-optimizer/.
