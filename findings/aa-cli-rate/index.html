    Subsidy factors

    How much API value a plan holds for its price. Plan cost per task is the API cost divided by this factor.

    Factor = API value of a month's allowance ÷ the plan's monthly price. A month is 4.345 weeks. The range runs from the low to the high end of the allowance estimate.

    Claude models share one weekly allowance on Max 20x but draw it down at different weights, so each has its own factor. Codex prices every model on one credit card, so a Codex plan has one factor.

    Read with care

    • Compare within one index. Coding Agent Index v2.0 replaced v1.5, and the two scales are not comparable. Intelligence Index v5.0 is a third scale.
    • Coding Agent v2.0 lists each model at max only. GPT-6.1 Terra is the exception, with every effort. Gemini 3.8 Flash runs there through the Antigravity SDK, which may not be the harness the gemini lane uses.
    • Odd points are as published. Fable 5.1 is listed "with fallback". On v5.0 it scores lower at max (49) than at xhigh (50). Gemini 3.8 Flash has no v5.0 cost at low, and no max or xhigh effort.
    • The two indexes price different work. GPT-6.1 Sol at max costs $1.27 a task on v5.0 and $1.50 on Coding Agent v2.0.
    • The scores were read by hand on 2026-10-31. The source site could not be reached from the session that built this page, so the figures were not re-fetched.
    • Plan rates assume you use the whole allowance every week. Allowance you leave unused makes each task dearer.
    • Some plan inputs are soft. Haiku's weekly weight is not measured yet, so its factor uses the 5-hour weight and has no upper bound. Opus uses the calibration floor of $2,700 a week, so its factor is a lower bound (shown as >=). The Pro Lite doubling on 2026-10-29 16:56 UTC is not re-measured. The Gemini allowance is a lower bound. On the Codex meter, Sol is charged about 1.19 to 1.36 times its card price, so its plan cost is likely higher than shown.
